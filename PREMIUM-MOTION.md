# Тест премиальных анимаций MARI LIMAR

Ветка: `feature/premium-motion`. Изменения не слиты в `main`.
Workflow GitHub Pages запускается только для `main`; его конфигурация не менялась.

## Что добавлено

- `assets/premium-motion.css` — фирменная шторка и CSS-fallback перехода, интеграция с существующим `.reveal`, сокращённое движение на телефонах.
- `assets/premium-motion.js` — View Transitions API для появления шторки, обычная HTML-навигация, одноразовые анимации текста через IntersectionObserver и Web Animations API.
- В 12 HTML-файлах добавлены только подключения модуля и невидимая служебная шторка. Разметка `<header>` и `<main>`, меню, кнопки, содержимое и порядок разделов сохранены побайтно.

Переход: около 380 мс на закрытие + 460 мс на раскрытие новой страницы (на телефоне 300 + 360 мс), без учёта сетевой загрузки. При медленной загрузке шторка на текущей странице освобождается через 1,8 с. После загрузки новой страницы маркер принимается только для соответствующего адреса и не старше 8 с. Кнопки браузера обслуживает сам браузер; история не переписывается.

На прокрутке: категория → заголовок → описание → кнопка, с шагом карточек 90 мс. По правке пользователя фото исключены из scroll-анимации: нет скрытия, шторки, задержки или масштабирования при появлении. Существующее наведение сохранено. Анимация заканчивается освобождением свойств, поэтому прежние hover-эффекты остаются в силе. Видео, фоновые hero-фото, меню, модальные окна и фотографии сравнения «До / После» не получают анимацию фото.

## Как посмотреть до публикации

Откройте отдельный закрытый Site-предпросмотр по ссылке, предоставленной в отчёте. Авторизуйтесь в ChatGPT под аккаунтом владельца, если потребуется. Это отдельная копия тестовой ветки, не рабочий GitHub Pages.

Также можно скачать ZIP ветки через GitHub → Code → Download ZIP, распаковать и запустить в каталоге:

```sh
python3 -m http.server 8000
```

Открыть `http://localhost:8000/index.html`. Открытие через `file://` не подходит для надёжной проверки переходов.

Для локальных логических проверок нужен Node.js 18+:

```sh
node --check assets/premium-motion.js
node --test tests/premium-motion.test.cjs
```

## Проверки и ограничения

10 автоматических сценариев проверяют все 12 маршрутов, исключения кликов, режим reduced motion, CSS-fallback, отказ View Transitions API/sessionStorage, двойной клик, watchdog и восстановление BFCache, одноразовое появление и сокращённое время на телефоне. Это изолированные проверки поведения, не эмуляция браузерного рендеринга. Проверены 516 локальных ссылок/ассетов; отсутствующих файлов нет.

Автоматический визуальный браузерный предпросмотр и проверка на реальном смартфоне в текущем окружении недоступны. В предпросмотре перед слиянием проверьте визуальную плавность, Back/Forward, переключение тем, меню, фильтры, ползунок «До / После», ширины 390/768/1440 px и системную настройку сокращённого движения. Объективные показатели Core Web Vitals требуют измерения на опубликованном тестовом адресе и реальных устройствах; улучшение или отсутствие регрессии пока не заявляются.

## Публикация и откат

Только после отдельного подтверждения пользователя: проверить ветку, выполнить merge в `main`, дождаться GitHub Pages и проверить опубликованный адрес. Не запускайте `workflow_dispatch` для тестовой ветки: workflow использует рабочий Pages environment.

Откат эффектов: удалить подключения `premium-motion.css` / `premium-motion.js` и `.pm-curtain` из HTML. Старые обработчики сайта и стили не переписывались, поэтому прежняя анимация `.reveal` восстановится автоматически.
