# WordPress staging — Марли Лимарт

Эта ветка (`wordpress-staging`) — независимая рабочая копия `main`. Не изменять `main`, не сливать ветку, не переключать источник GitHub Pages и не менять действующий сайт без отдельного подтверждения.

## Цель
Адаптировать текущий HTML/CSS/JS-сайт под отдельную тему WordPress для тестового хостинга REG.RU: `u3716889.isp.regruhosting.ru`.

## Обязательные требования
- Сохранить визуальную идентичность, структуру страниц, анимации, адаптивный дизайн, фотографии и видео.
- В редакторе WordPress обеспечить изменения заголовков, текстов, изображений, шрифтов, порядка и видимости блоков.
- Каталог кухонь и гардеробных — отдельные типы записей с галереями и характеристиками, новые карточки добавляются без кода.
- Блог — стандартные записи Gutenberg с фотографиями и рубриками.
- Перенести формы, карусели, фильтры и интерактивные элементы без потери поведения.
- Обязательно проверить технику/фотографии/формы, контакты, SEO и мобильную версию перед запуском.
- Основной сайт продолжает работать через GitHub Pages из `main`.

## Этапы
1. Инвентаризация текущих HTML, CSS, JS и ассетов, выбор редактируемых зон и шаблонов.
2. Создание оригинальной темы WordPress; подключение активов и шаблонов с сохранением дизайна.
3. Настройка блочных шаблонов Gutenberg и управления шрифтами/блоками.
4. Типы записей «Кухни», «Гардеробные», «Проекты»; импорт данных и галерей.
5. Импорт блога и медиа, перенастройка внутренних ссылок и форм.
6. Установка на тестовом хостинге, сравнение страниц с оригиналом, исправление отклонений.
7. Тест владельцем; затем домен, доверенный SSL и тест заказчицей.

## Условия тестирования
Использовать тестовый WordPress без реальных заявок и персональных данных до установки доверенного SSL. Данные доступа не сохранять в репозитории.

**Важно:** ветка GitHub сама по себе не может быть установлена как WordPress. Для этого требуется законченная тема, её ZIP-пакет и загрузка в WordPress либо развертывание через файловый менеджер. Наличие ветки не означает, что перенос уже выполнен.
