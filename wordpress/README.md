# WordPress staging — 8 ноября 2026

Тема установлена и активирована на u3716889.isp.regruhosting.ru. Импортировано 61 исходных HTML-страниц: 12 страниц, 27 кухонь, 10 гардеробных, 12 записей блога. Главная — index. Исходные Sample Page, Hello world и черновик Privacy Policy сохранены.

## Сборка
Установить beautifulsoup4. Из корня репозитория выполнить `python wordpress/build_theme.py`, затем `python wordpress/verify_theme.py`. Скрипт собирает theme/import.json и копирует assets из исходного сайта. Архивировать папку theme с именем marli-limart. Импорт запускается из Внешний вид → Перенос сайта; уже импортированные записи повторно не создаются и изменения владельца не перезаписываются.
